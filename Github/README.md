# 🐍 Mini-Ecosystem

**Mini-Ecosystem** is a small Python CLI system that combines several standalone programs into one menu.

The project is mainly built for learning Python, experimenting with CLI applications, and gradually creating a personal collection of useful tools and games.

## 📦 Project Structure

```text
Mini-Ecosystem/
├── ecosystem.py       # Main launcher
├── Calcypython.py     # Calculator
├── Calcyold.py        # Previous calculator version
└── games.py           # Mini-games
```

## 🚀 Features

### 🧮 Calculator

Launches the custom **Calcypython** calculator with support for:

* `+` — Addition
* `-` — Subtraction
* `*` — Multiplication
* `/` — Division
* `//` — Floor division
* `%` — Modulo
* `**` — Exponentiation

### 🎮 Games

Built-in mini-games:

1. 🎰 Slot Machine
2. 🪨📄✂️ P.S.R. (Rock Paper Scissors)
3. 🔢 Guess the Number

### 🕐 Date & Time

Displays the current date and time using Python's `datetime` module.

### 🌍 Random Greetings

Generates random greetings for the user.

## 🛠️ Technologies

* 🐍 Python
* `random`
* `datetime`
* `while` loops
* `if / elif / else`
* Python modules and `import`

## ▶️ Running the Project

  Windows
run ecosystem.exe

  Linux
run ecosystem 
## 🎯 Project Goal

Mini-Ecosystem is primarily a learning and experimental project.

The main idea is to keep the launcher simple while adding new programs as separate Python modules.

Instead of putting everything into one huge file, each part of the ecosystem can have its own module.
